The relay starts at {{ .Values.publicUrl }}.
It keeps its state in {{ if eq (include "relay.store" .) "json" }}files on the volume {{ include "relay.claimName" . }}{{ else }}Temporal at {{ .Values.temporal.address }}{{ end }}.

On its first start it prints a pairing code. Read it with:

  kubectl logs -n {{ .Release.Namespace }} deploy/{{ include "relay.fullname" . }} | grep -A3 "Pairing code"

For a new code:

  kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "relay.fullname" . }} -- relay pair-code

Then pair the Mac: Spec Studio > Settings > Remote Relay, or
  studio agent pair {{ .Values.publicUrl | replace "https://" "wss://" | replace "http://" "ws://" }}/agent <code>

Add the MCP connector in Claude AI with the URL {{ .Values.publicUrl }}/mcp.
